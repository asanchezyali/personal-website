Si $A$ y $B$ representan transformaciones lineales, la composición $T_A \circ T_B$ es también lineal,
y la matriz que la representa es el producto $AB$. El producto de matrices se define precisamente
para que esa correspondencia se cumpla.

## Orden de aplicación

La notación sigue la de la composición de funciones: en $AB\vec{v}$ se aplica primero $B$ y después
$A$, igual que en $f(g(x))$. La lectura es de derecha a izquierda.

```python
import numpy as np

R = np.array([[0, -1], [1, 0]])   # rotación de π/2
S = np.array([[2,  0], [0, 1]])   # dilatación de razón 2 en el primer eje

R @ S     # array([[ 0, -1], [ 2,  0]])
S @ R     # array([[ 0, -2], [ 1,  0]])
```

En general $AB \neq BA$. El producto de matrices **no es conmutativo**, propiedad que se sigue de
que la composición de funciones tampoco lo es. Sí es asociativo, $(AB)C = A(BC)$, porque la
composición lo es.

## Matriz inversa

Una matriz cuadrada $A \in \mathbb{R}^{n\times n}$ es **invertible** si existe $A^{-1}$ tal que

$$
A^{-1}A = AA^{-1} = I_n
$$

La inversa, cuando existe, es única, y representa la transformación que deshace $T_A$. Una matriz
invertible se denomina también **regular**, y **singular** en caso contrario.

```python
A = np.array([[2, 1],
              [1, 1]])

np.linalg.inv(A)
# array([[ 1., -1.],
#        [-1.,  2.]])
```

## Caracterización de la singularidad

Las siguientes afirmaciones sobre $A \in \mathbb{R}^{n\times n}$ son equivalentes:

$$
\begin{aligned}
&A \text{ es invertible} \iff \det A \neq 0 \iff \operatorname{rank}(A) = n\\
&\iff \text{las columnas de } A \text{ son linealmente independientes}\\
&\iff T_A \text{ es biyectiva} \iff A\vec{x} = \vec{0} \text{ solo admite } \vec{x} = \vec{0}
\end{aligned}
$$

Cuando $\det A = 0$, la imagen de $T_A$ tiene dimensión menor que $n$. La transformación deja de ser
inyectiva: existen $\vec{u} \neq \vec{v}$ con $T_A(\vec{u}) = T_A(\vec{v})$, y ninguna aplicación
puede recuperar el argumento a partir de la imagen. El conjunto de vectores que $A$ envía al origen
es el **núcleo** de $T_A$, y tiene dimensión positiva exactamente cuando $A$ es singular.

```python
B = np.array([[2, 4],
              [1, 2]])       # segunda columna = 2 · primera columna

np.linalg.inv(B)
# LinAlgError: Singular matrix
```

NumPy lanza una excepción en lugar de devolver un resultado aproximado, comportamiento preferible:
una matriz singular no tiene inversa y cualquier valor devuelto sería espurio.

## Resolución de sistemas

El sistema $A\vec{x} = \vec{b}$ pregunta qué vector tiene a $\vec{b}$ por imagen bajo $T_A$. Con $A$
invertible la respuesta es $\vec{x} = A^{-1}\vec{b}$, única por biyectividad.

```python
b = np.array([5, 3])
np.linalg.solve(A, b)     # array([2., 1.])
```

La equivalencia es matemática pero no numérica: como se argumentó en la lección sobre sistemas lineales, `solve` es
preferible a `inv` por coste y por estabilidad.
