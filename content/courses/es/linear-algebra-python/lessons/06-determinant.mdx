El determinante suele introducirse como una fórmula que conviene memorizar, $ad - bc$. Se trata, sin
embargo, de un número con un significado geométrico preciso, y una vez comprendido ese significado
la fórmula deja de requerir memorización.

## ¿Qué mide el determinante?

El determinante de una matriz es **el factor por el que queda multiplicada el área** al aplicar la
transformación.

Considérese el cuadrado unitario, el que forman $\hat{\imath}$ y $\hat{\jmath}$, de área 1. Al
aplicarle la matriz, el área de la figura resultante *coincide* con el determinante.

La región de color morado es la imagen del cuadrado unitario, y el valor numérico la acompaña en
todo momento:

- $\det = 1$ indica que el área permanece constante. Las rotaciones y los cizallamientos pertenecen
  a este grupo.
- $\det = 3$ indica que el área se triplica.
- $\det = 0.5$ indica que el área se reduce a la mitad.

## El significado del valor cero

Cuando el determinante alcanza el valor cero, la región morada desaparece: el plano completo se ha
aplastado sobre una recta.

Esa condición conecta las lecciones anteriores en una sola afirmación: **$\det A = 0$ si y solo si
las columnas de $A$ son linealmente dependientes**, si y solo si el span degenera, si y solo si $A$
carece de inversa. Son cuatro formulaciones equivalentes de un mismo hecho.

```python
import numpy as np

np.linalg.det(np.array([[2, 1], [1, 1]]))   # 1.0  → invertible
np.linalg.det(np.array([[2, 4], [1, 2]]))   # 0.0  → singular
```

## El signo

La fórmula no lo sugiere, pero el determinante puede tomar valores **negativos**.

Fijando $a = -1$ y dejando el resto de las entradas en la identidad, el determinante pasa a valer
$-1$. El área conserva su magnitud, pero el plano ha quedado **invertido**: lo que se situaba a la
izquierda de $\hat{\imath}$ pasa a situarse a la derecha.

El signo registra, por tanto, la orientación. Si es positivo, el plano conserva su sentido; si es
negativo, se ha producido una reflexión.

## ¿Por qué la fórmula adopta esa forma?

Con la interpretación geométrica establecida, la expresión $ad - bc$ deja de resultar arbitraria.

Las columnas de la matriz son los dos lados del paralelogramo en que se ha convertido el cuadrado
unitario: $(a, c)$ y $(b, d)$. El área de un paralelogramo definido por esos lados es exactamente
$|ad - bc|$, resultado que se obtiene restando al rectángulo que lo contiene los triángulos
sobrantes. La fórmula *es* el área.

## Una propiedad inmediata

$$\det(AB) = \det(A)\det(B)$$

Expresada en palabras, la propiedad resulta casi evidente: si $B$ triplica el área y $A$ la duplica,
aplicar ambas de forma consecutiva la multiplica por seis. La demostración algebraica es laboriosa,
mientras que la justificación geométrica es inmediata.

```python
A = np.array([[2, 0], [0, 1]])
B = np.array([[1, 1], [0, 1]])

np.linalg.det(A @ B)                          # 2.0
np.linalg.det(A) * np.linalg.det(B)           # 2.0
```
