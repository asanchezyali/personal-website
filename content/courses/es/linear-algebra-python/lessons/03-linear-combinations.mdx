Disponemos ya de las dos operaciones fundamentales: sumar y escalar. Al combinarlas se obtiene la
construcción central de todo el curso.

Dados dos vectores $\vec{v}$ y $\vec{w}$ y dos números $s$ y $t$, la expresión

$$s\vec{v} + t\vec{w}$$

recibe el nombre de **combinación lineal**: cada vector se escala por su coeficiente y los
resultados se suman.

La cuestión relevante, una vez explorados los valores, es la siguiente: **¿qué puntos del plano
resultan alcanzables?**

## El span

El conjunto de todos los puntos alcanzables mediante combinaciones lineales se denomina **span** de
$\vec{v}$ y $\vec{w}$.

Con los valores anteriores, la respuesta es *el plano completo*. Cualquier punto admite un par
$(s, t)$ que lo alcanza. Dos vectores que apunten en direcciones distintas bastan para generar
$\mathbb{R}^2$ en su totalidad.

```python
import numpy as np

v = np.array([2, 1])
w = np.array([-1, 2])

# ¿Qué combinación alcanza (4, 3)?
np.linalg.solve(np.column_stack([v, w]), np.array([4, 3]))
# array([2.2, 0.4])  →  2.2·v + 0.4·w = (4, 3)
```

Esa llamada a `solve` refleja lo que hace en el fondo cualquier resolución de un sistema de
ecuaciones: determinar los coeficientes de una combinación lineal.

## La degeneración del span

El caso relevante se presenta cuando ambos vectores apuntan en la **misma** dirección.

Con $\vec{v} = (2, 1)$ y $\vec{w} = (4, 2)$ —el segundo es el doble del primero— el resultado no
abandona en ningún momento una única recta, cualesquiera que sean los coeficientes. El span ha
pasado de ser un plano a ser una línea.

En esa situación los vectores se denominan **linealmente dependientes**: uno de ellos no aporta
información nueva, por estar ya contenido en el otro. Cuando son independientes, el span abarca el
plano completo.

```python
# El determinante detecta exactamente esta condición (lección 6)
np.linalg.det(np.column_stack([[2, 1], [4, 2]]))   # 0.0  → dependientes
np.linalg.det(np.column_stack([[2, 1], [-1, 2]]))  # 5.0  → independientes
```

## Base

Un conjunto de vectores independientes cuyo span abarca todo el espacio constituye una **base**. Los
dos vectores empleados más arriba forman una base de $\mathbb{R}^2$.

La base de referencia habitual es la formada por $\hat{\imath} = (1, 0)$ y $\hat{\jmath} = (0, 1)$:

De ahí se desprende una observación importante: **escribir un vector como $(3, 2)$ supone ya emplear
una combinación lineal**, aunque la base sea tan habitual que no se mencione. Las coordenadas son
siempre coordenadas *respecto a una base determinada*.

Esa observación conduce directamente al siguiente módulo: si un cambio de base modifica las
coordenadas, una matriz puede entenderse como la especificación del destino de cada vector de la
base.
