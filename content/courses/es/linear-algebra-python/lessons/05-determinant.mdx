El determinante suele presentarse como una fórmula que hay que memorizar: $ad - bc$. Pero es un
número con un significado geométrico muy nítido, y una vez que lo ves, la fórmula deja de hacer
falta.

## Qué mide

El determinante de una matriz es **el factor por el que se multiplica el área** cuando aplicas la
transformación.

Toma el cuadrado unitario — el que forman $\hat{\imath}$ y $\hat{\jmath}$, de área 1. Aplícale la
matriz. El área de la figura resultante *es* el determinante.

La región morada es la imagen del cuadrado unitario. Muévela y observa cómo el número la sigue.

- $\det = 1$ → el área no cambia. Rotaciones y cizallamientos son de este tipo.
- $\det = 3$ → todo ocupa el triple.
- $\det = 0.5$ → todo se encoge a la mitad.

## Cero significa colapso

Lleva el determinante a cero. La región morada desaparece porque el plano entero se aplastó sobre
una recta.

Esto conecta las tres lecciones anteriores en una sola frase: **$\det A = 0$ si y solo si las
columnas de $A$ son linealmente dependientes**, si y solo si el span colapsa, si y solo si $A$ no
tiene inversa. Son cuatro maneras de decir lo mismo.

```python
import numpy as np

np.linalg.det(np.array([[2, 1], [1, 1]]))   # 1.0  → invertible
np.linalg.det(np.array([[2, 4], [1, 2]]))   # 0.0  → singular
```

## El signo

Ahora algo que la fórmula no sugiere: el determinante puede ser **negativo**.

Pon $a = -1$ dejando el resto en la identidad. El determinante se vuelve $-1$. El área sigue
siendo 1 en magnitud, pero el plano se **dio la vuelta**: lo que antes estaba a la izquierda de
$\hat{\imath}$ ahora está a la derecha.

El signo registra la orientación. Positivo, el plano conserva su sentido; negativo, se reflejó.

## Por qué la fórmula es esa

Con la interpretación en mano, $ad - bc$ deja de ser arbitraria.

Las columnas de la matriz son los dos lados del paralelogramo en que se convirtió el cuadrado
unitario: $(a, c)$ y $(b, d)$. El área de un paralelogramo con esos lados es exactamente
$|ad - bc|$ — sale de restarle al rectángulo que lo contiene los triángulos que sobran. La fórmula
*es* el área.

## Una propiedad que sale gratis

$$\det(AB) = \det(A)\det(B)$$

Que en palabras es casi una obviedad: si $B$ triplica el área y $A$ la duplica, aplicar las dos
seguidas la multiplica por seis. Demostrarlo con las fórmulas es tedioso; verlo geométricamente es
inmediato.

```python
A = np.array([[2, 0], [0, 1]])
B = np.array([[1, 1], [0, 1]])

np.linalg.det(A @ B)                          # 2.0
np.linalg.det(A) * np.linalg.det(B)           # 2.0
```
