Si una matriz representa una transformación, el producto de dos matrices ha de significar
necesariamente **aplicar una y a continuación la otra**. El producto de matrices no es otra cosa.

## El orden de aplicación

La expresión $AB$ indica que se aplica $B$ en primer lugar y $A$ después. Se lee de derecha a
izquierda, igual que la composición de funciones $f(g(x))$.

```python
import numpy as np

R = np.array([[0, -1], [1, 0]])   # rotación de 90°
S = np.array([[2,  0], [0, 1]])   # dilatación del eje x al doble

R @ S     # array([[ 0, -1], [ 2,  0]])
S @ R     # array([[ 0, -2], [ 1,  0]])
```

Los resultados difieren. Dilatar y girar después no equivale a girar y dilatar después, una
distinción evidente desde la interpretación geométrica y completamente opaca si se atiende
únicamente a la regla de filas por columnas.

Esa es la razón de fondo por la que el producto de matrices **no es conmutativo**. No se trata de
una singularidad del álgebra: la composición de funciones tampoco lo es.

## La transformación inversa

Si $A$ transforma el plano, cabe preguntarse si existe una matriz que lo devuelva a su estado
original. Esa matriz es la **inversa**, $A^{-1}$, y satisface:

$$A^{-1}A = I$$

donde $I$ designa la identidad, la matriz que deja el plano inalterado.

```python
A = np.array([[2, 1],
              [1, 1]])

A_inv = np.linalg.inv(A)
# array([[ 1., -1.],
#        [-1.,  2.]])

A_inv @ A     # la identidad, salvo error de coma flotante
```

## Cuando la transformación no es reversible

Al desplazar los deslizadores hasta que la cuadrícula se aplasta sobre una recta, el indicador
inferior señala el momento en que se produce esa condición.

Cuando el plano colapsa, la transformación **destruye información**. Dos puntos distintos del plano
original terminan ocupando la misma posición, y ninguna matriz puede volver a separarlos, puesto que
carecería de criterio para decidir el origen de cada punto.

En esas condiciones la matriz se denomina **singular** y no admite inversa.

```python
B = np.array([[2, 4],
              [1, 2]])       # la segunda columna es el doble de la primera

np.linalg.inv(B)
# LinAlgError: Singular matrix
```

NumPy no devuelve un resultado aproximado sino un error, comportamiento preferible en la práctica:
un sistema sin solución única debe señalarlo explícitamente en lugar de proporcionar un valor
arbitrario.

## La resolución de sistemas como inversión

Un sistema de ecuaciones $A\vec{x} = \vec{b}$ plantea la siguiente cuestión: *¿qué vector, al ser
transformado por $A$, se convierte en $\vec{b}$?* Se trata de la transformación en sentido inverso.

```python
b = np.array([5, 3])
np.linalg.solve(A, b)     # array([2., 1.])
```

Conviene insistir en una recomendación práctica: aunque $A^{-1}b$ produce el mismo resultado en
términos matemáticos, es preferible **emplear `solve` y no `inv`**. Calcular la inversa completa
resulta más costoso y numéricamente menos estable que resolver el sistema de forma directa. La
diferencia solo se aprecia con matrices de tamaño considerable, momento en el que el coste ya es
relevante.
