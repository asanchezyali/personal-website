La pregunta admite tres respuestas distintas según a quién se le formule, y las tres son correctas.

Un **físico** describirá un vector como una flecha en el espacio, dotada de magnitud y dirección,
que puede desplazarse sin dejar de ser la misma flecha. Un **programador** lo definirá como una
lista de números. Un **matemático** dirá que se trata de un elemento de un espacio vectorial, y
acompañará la definición de una lista de axiomas.

Las tres caracterizaciones son válidas. Para trabajar, sin embargo, la primera aporta la intuición y
la segunda es la que se ejecuta, y buena parte del álgebra lineal consiste precisamente en
transitar entre ambas.

## El vector como desplazamiento

Conviene interpretar $\vec{v} = (3, 2)$ no como un punto, sino como una **instrucción de
desplazamiento**: tres unidades hacia la derecha y dos hacia arriba, tomando el origen como punto de
partida.

En NumPy esa instrucción se representa, literalmente, como una lista:

```python
import numpy as np

v = np.array([3, 2])
w = np.array([-2, 3])
```

## La suma como encadenamiento

Aquí aparece la primera idea que conviene fijar con claridad. La suma de dos vectores no responde a
una regla arbitraria sobre listas de números: consiste en realizar un desplazamiento y a
continuación el otro.

Si $\vec{v}$ indica «tres a la derecha, dos arriba» y $\vec{w}$ indica «dos a la izquierda, tres
arriba», ejecutar ambos de forma consecutiva conduce a $(1, 5)$, que es exactamente el resultado de
sumar componente a componente.

```python
v + w
# array([1, 5])
```

Esa correspondencia —trasladar el punto de partida al extremo de la primera flecha— se conoce como
disponer los vectores *punta con cola*, y explica por qué la suma se define de este modo y no de
otro.

## El producto por un escalar

Multiplicar por un número **escala** la instrucción sin alterar su dirección:

```python
2 * v        # array([6, 4])   — el doble de distancia, misma dirección
-1 * v       # array([-3, -2]) — misma recta, sentido opuesto
0.5 * v      # array([1.5, 1.0])
```

Un factor negativo invierte el sentido de la flecha. De ahí que a los números se les denomine
**escalares** en este contexto: su única función consiste en escalar.

## La longitud

La magnitud de un vector se obtiene del teorema de Pitágoras, dado que sus componentes constituyen
los catetos de un triángulo rectángulo:

$$\|\vec{v}\| = \sqrt{v_1^2 + v_2^2}$$

```python
np.linalg.norm(v)
# 3.605551275463989
```

Un vector de longitud 1 recibe el nombre de **unitario**, y resulta útil para referirse a una
dirección sin mezclarla con la magnitud:

```python
v / np.linalg.norm(v)
# array([0.83205029, 0.5547002])
```

## ¿Por qué esto importa después?

Todo el contenido posterior se apoya en dos operaciones: la suma de vectores y el producto por un
escalar. No hay más. Las matrices, los determinantes y los vectores propios se construyen sobre esas
dos.

Un espacio vectorial es, de hecho, *cualquier* conjunto en el que ambas operaciones se comporten
como aquí. Esa generalidad explica que el álgebra lineal aparezca en contextos que no guardan
relación aparente con la geometría: los *embeddings* de un modelo de lenguaje son vectores porque
admiten suma y escalado, y esa condición basta para que toda la maquinaria resulte aplicable.
