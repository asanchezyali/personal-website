El álgebra lineal suele enseñarse como una sucesión de procedimientos: multiplicar estas filas por
estas columnas, calcular este determinante, resolver este sistema. Es posible completar un curso
entero de ese modo sin llegar a comprender qué significa ninguna de esas operaciones.

Este curso invierte el orden. Cada concepto se introduce mediante una figura manipulable y se cierra
con las pocas líneas de NumPy que realizan la operación equivalente. El cálculo llega después de la
intuición geométrica, no antes.

## ¿Qué necesitas?

Conocimientos básicos de Python y familiaridad con el plano cartesiano. Nada más. No se requiere
haber estudiado álgebra lineal previamente; quienes la hayan cursado y conserven la impresión de
haber memorizado procedimientos encontrarán aquí el enfoque complementario.

Para ejecutar los ejemplos:

```bash
pip install numpy
```

## ¿Cómo está organizado?

El curso consta de tres módulos consecutivos. El primero parte de la resolución de **sistemas
lineales** con NumPy —el problema que motiva toda la disciplina— y continúa con los **vectores**: su
definición y las construcciones que admiten. El segundo presenta las **matrices como funciones** que
transforman el plano, interpretación sobre la que se apoya el resto del material. El tercero aborda
los **vectores propios**, las direcciones que una transformación no consigue desviar.

Cada lección incorpora una figura interactiva. Conviene manipularla antes de leer la explicación
correspondiente, ya que la intuición geométrica facilita considerablemente la lectura posterior.
