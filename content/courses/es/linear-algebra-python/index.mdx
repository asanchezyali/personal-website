El álgebra lineal se enseña casi siempre como una lista de procedimientos: multiplica estas filas
por estas columnas, calcula este determinante, resuelve este sistema. Se puede aprobar un curso
entero así sin llegar a saber **qué significa** ninguna de esas operaciones.

Este curso va al revés. Cada idea empieza con una figura que puedes mover con el ratón, y termina
con las tres o cuatro líneas de NumPy que hacen lo mismo. La cuenta viene después de la intuición,
no antes.

## Qué necesitas

Saber programar un poco en Python y recordar qué es un plano cartesiano. Nada más. No hace falta
haber visto álgebra lineal antes; si ya la viste y te quedó la sensación de haber memorizado
recetas, este curso es justamente para eso.

Para correr los ejemplos:

```bash
pip install numpy
```

## Cómo está organizado

Tres módulos que construyen uno sobre otro. El primero es sobre **vectores** — qué son y qué se
puede armar con ellos. El segundo trata las **matrices como funciones** que mueven el plano, que es
la idea que hace que todo lo demás encaje. El tercero llega a los **vectores propios**: las
direcciones que una transformación no logra torcer.

Cada lección tiene una figura interactiva. Muévela antes de leer la explicación — la intuición
entra por ahí.
