Linear algebra is usually taught as a sequence of procedures: multiply these rows by these columns,
compute this determinant, solve this system. It is possible to complete an entire course that way
without ever grasping what any of those operations mean.

This course reverses the order. Each concept is introduced through a figure that can be manipulated
and closes with the few lines of NumPy that perform the equivalent operation. The computation comes
after the geometric intuition, not before it.

## What you need

A basic command of Python and familiarity with the Cartesian plane. Nothing more. No prior study of
linear algebra is required; those who have taken a course and retain the impression of having
memorised procedures will find the complementary approach here.

To run the examples:

```bash
pip install numpy
```

## How it is organised

The course consists of three consecutive modules. The first begins with solving **linear systems**
in NumPy — the problem that motivates the whole discipline — and continues with **vectors**: their
definition and the constructions they admit. The second presents **matrices as functions** that
transform the plane, an interpretation on which the remaining material rests. The third addresses
**eigenvectors**, the directions a transformation cannot deflect.

Each lesson includes an interactive figure. It is worth manipulating it before reading the
corresponding explanation, since the geometric intuition makes the subsequent reading considerably
easier.
