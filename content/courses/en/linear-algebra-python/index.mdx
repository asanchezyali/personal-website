Linear algebra is almost always taught as a list of procedures: multiply these rows by these
columns, compute this determinant, solve this system. You can pass an entire course that way
without ever learning **what any of it means**.

This course goes the other way round. Every idea starts with a figure you can move with your mouse,
and ends with the three or four lines of NumPy that do the same thing. The arithmetic comes after
the intuition, not before it.

## What you need

A little Python, and a memory of what a Cartesian plane is. That's it. No prior linear algebra
required — and if you have taken it and came away feeling you'd memorised recipes, this is exactly
what it's for.

To run the examples:

```bash
pip install numpy
```

## How it's organised

Three modules, each built on the last. The first is about **vectors** — what they are and what you
can build from them. The second treats **matrices as functions** that move the plane, which is the
idea that makes everything else fit together. The third reaches **eigenvectors**: the directions a
transformation cannot manage to twist.

Every lesson has an interactive figure. Move it before reading the explanation — that's where the
intuition comes from.
