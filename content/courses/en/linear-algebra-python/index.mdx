Linear algebra is customarily taught as a sequence of algorithms: multiply rows by columns, expand a
determinant, reduce a system. The outcome is operational competence without semantic content, in
which procedures are executed correctly without any grasp of what they represent.

This course reverses the order of exposition. Each concept is introduced through its geometric
interpretation, supported by a figure that can be manipulated, and closes with the formal definition
and its implementation in NumPy. Computation is presented as a consequence of the definition rather
than as the starting point.

## Prerequisites

A basic command of Python and familiarity with the Cartesian plane. No prior background in linear
algebra is assumed.

```bash
pip install numpy
```

## Organisation

The course consists of three consecutive modules.

The **first** starts from systems of linear equations, the problem that historically motivates the
discipline, continues with the matrix as a data structure — shape, memory layout, broadcasting and
the product — and then establishes the vector space structure: linear combination, span, linear
dependence and basis.

The **second** defines linear transformations and establishes their bijective correspondence with
matrices through the image of a basis. From there follow the matrix product as composition, the
inverse matrix, and the determinant as the area scale factor.

The **third** addresses eigenvalues and eigenvectors, which identify the invariant directions of a
transformation and describe its behaviour under iteration.

Each lesson includes at least one interactive figure. Exploring the figure beforehand eases the
reading of the algebraic formulation that accompanies it.
