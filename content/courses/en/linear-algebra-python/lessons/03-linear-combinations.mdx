Given $\vec{v}_1,\dots,\vec{v}_k \in V$ and scalars $\lambda_1,\dots,\lambda_k \in \mathbb{R}$, the
vector

$$
\sum_{i=1}^{k} \lambda_i \vec{v}_i = \lambda_1\vec{v}_1 + \cdots + \lambda_k\vec{v}_k
$$

is a **linear combination** of $\vec{v}_1,\dots,\vec{v}_k$. For $k = 2$ in $\mathbb{R}^2$ the
expression reduces to $s\vec{v} + t\vec{w}$.

## Spanned subspace

The **span** of a set of vectors is the set of all their linear combinations:

$$
\operatorname{span}\{\vec{v},\vec{w}\} = \{\, s\vec{v} + t\vec{w} \;:\; s,t \in \mathbb{R} \,\}
$$

A span is always a vector subspace: it contains $\vec{0}$ and is closed under addition and scalar
multiplication. In $\mathbb{R}^2$ the only possible subspaces are $\{\vec{0}\}$, the lines through
the origin, and $\mathbb{R}^2$ itself.

Determining whether a vector $\vec{u}$ belongs to the span amounts to solving a linear system whose
unknowns are the coefficients:

```python
import numpy as np

v = np.array([2, 1])
w = np.array([-1, 2])

np.linalg.solve(np.column_stack([v, w]), np.array([4, 3]))
# array([2.2, 0.4])   →   2.2·v + 0.4·w = (4, 3)
```

The equivalence is exact: $A\vec{x} = \vec{b}$ asks which linear combination of the columns of $A$
produces $\vec{b}$.

## Linear dependence

The vectors $\vec{v}_1,\dots,\vec{v}_k$ are **linearly independent** when

$$
\sum_{i=1}^{k} \lambda_i \vec{v}_i = \vec{0} \;\Longrightarrow\; \lambda_1 = \cdots = \lambda_k = 0
$$

and **linearly dependent** otherwise. Dependence means that one of the vectors belongs to the span of
the remaining ones and therefore does not enlarge the spanned subspace.

For $\vec{v} = (2,1)$ and $\vec{w} = (4,2)$ the relation $\vec{w} = 2\vec{v}$ holds, so
$\operatorname{span}\{\vec{v},\vec{w}\} = \operatorname{span}\{\vec{v}\}$, a line. No choice of
coefficients produces a point outside it.

In $\mathbb{R}^2$, two vectors are linearly independent if and only if the determinant of the matrix
having them as columns is non-zero:

```python
np.linalg.det(np.column_stack([[2, 1], [4, 2]]))   # 0.0  → dependent
np.linalg.det(np.column_stack([[2, 1], [-1, 2]]))  # 5.0  → independent
```

The geometric justification of that criterion belongs to lesson 6.

## Basis

A **basis** of a vector space $V$ is a set of linearly independent vectors whose span is $V$. Every
basis of $\mathbb{R}^n$ has exactly $n$ elements, a number that defines the **dimension** of the
space.

The canonical basis of $\mathbb{R}^2$ is $\{\hat{\imath}, \hat{\jmath}\}$ with $\hat{\imath} = (1,0)$
and $\hat{\jmath} = (0,1)$.

If $\mathcal{B} = \{\vec{b}_1,\vec{b}_2\}$ is a basis, every $\vec{u} \in \mathbb{R}^2$ admits a
representation $\vec{u} = \lambda_1\vec{b}_1 + \lambda_2\vec{b}_2$, and the coefficients
$(\lambda_1,\lambda_2)$ are **unique**: uniqueness follows from linear independence.

An immediate consequence: the notation $(3,2)$ does not designate a vector in the abstract but its
coordinates with respect to a particular basis. Coordinates are always relative to a basis, and the
canonical one is omitted by convention.

That observation leads into the next module. If a change of basis transforms the coordinates, a
matrix can be read as the specification of the image of each basis vector.
