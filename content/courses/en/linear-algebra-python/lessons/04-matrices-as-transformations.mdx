This lesson articulates the rest of the course: the ideas that follow depend on the interpretation
presented here.

A $2 \times 2$ matrix is not a table of numbers but a function that takes the entire plane and
transforms it in such a way that lines remain lines, retain their uniform spacing, and the origin
stays fixed. A function with those properties is called a **linear transformation**.

## The principle that simplifies everything

Since every vector is a linear combination of $\hat{\imath}$ and $\hat{\jmath}$ — as seen in the
previous lesson — determining where *any* vector goes requires only knowing where those two go.

That is precisely the information a matrix stores: **its columns are the images of $\hat{\imath}$
and $\hat{\jmath}$**.

$$A = \begin{bmatrix} a & b \\ c & d \end{bmatrix} \quad\Longrightarrow\quad \hat{\imath} \mapsto \begin{bmatrix} a \\ c \end{bmatrix}, \qquad \hat{\jmath} \mapsto \begin{bmatrix} b \\ d \end{bmatrix}$$

The rest follows. If $\hat{\imath}$ maps to $(a, c)$ and $\hat{\jmath}$ maps to $(b, d)$, then
$(x, y) = x\hat{\imath} + y\hat{\jmath}$ must map to $x(a,c) + y(b,d)$. Expanding that expression
yields the familiar multiplication rule:

$$A\vec{v} = \begin{bmatrix} ax + by \\ cx + dy \end{bmatrix}$$

The rule is not arbitrary: it is the only one compatible with linearity.

Several configurations are particularly illustrative:

- With $\begin{bmatrix}1&0\\0&1\end{bmatrix}$ nothing moves. This is the **identity**.
- With $a = 0$, $b = -1$, $c = 1$, $d = 0$ the plane rotates by 90°.
- With $a = 2$ and $d = 2$ everything moves twice as far from the origin.
- With $b = 1$ and the rest unchanged the result is a **shear**: vertical lines tilt.
- If both columns become parallel, the plane flattens onto a line. That situation is taken up again
  in the lesson on the determinant.

## The operation in NumPy

```python
import numpy as np

A = np.array([[0, -1],
              [1,  0]])     # 90° rotation

v = np.array([3, 2])
A @ v                       # array([-2, 3])
```

The `@` operator corresponds to matrix multiplication. It should not be confused with `*`, which in
NumPy multiplies element by element, an entirely different operation.

The central claim can be checked directly:

```python
A @ np.array([1, 0])    # array([0, 1])  — first column of A
A @ np.array([0, 1])    # array([-1, 0]) — second column of A
```

The columns are, in a literal sense, the images of the basis vectors.

## Why "linear"?

The transformation satisfies two properties, from which the name of the whole discipline derives:

$$A(\vec{v} + \vec{w}) = A\vec{v} + A\vec{w} \qquad A(s\vec{v}) = s(A\vec{v})$$

Put in words: the order between adding and transforming is immaterial, as is the order between
scaling and transforming. That is why knowing the image of the basis suffices — any other vector is
built by adding and scaling, and the transformation respects both operations.
