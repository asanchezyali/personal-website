If $A$ and $B$ represent linear transformations, the composition $T_A \circ T_B$ is also linear, and
the matrix representing it is the product $AB$. The matrix product is defined precisely so that this
correspondence holds.

## Order of application

The notation follows that of function composition: in $AB\vec{v}$ the matrix $B$ is applied first
and $A$ afterwards, as in $f(g(x))$. It reads right to left.

```python
import numpy as np

R = np.array([[0, -1], [1, 0]])   # rotation by π/2
S = np.array([[2,  0], [0, 1]])   # scaling by 2 along the first axis

R @ S     # array([[ 0, -1], [ 2,  0]])
S @ R     # array([[ 0, -2], [ 1,  0]])
```

In general $AB \neq BA$. The matrix product **is not commutative**, a property that follows from the
fact that function composition is not commutative either. It is associative, $(AB)C = A(BC)$,
because composition is.

## The inverse matrix

A square matrix $A \in \mathbb{R}^{n\times n}$ is **invertible** if there exists $A^{-1}$ such that

$$
A^{-1}A = AA^{-1} = I_n
$$

The inverse, when it exists, is unique, and represents the transformation that undoes $T_A$. An
invertible matrix is also called **non-singular**, and **singular** otherwise.

```python
A = np.array([[2, 1],
              [1, 1]])

np.linalg.inv(A)
# array([[ 1., -1.],
#        [-1.,  2.]])
```

## Characterisation of singularity

The following statements about $A \in \mathbb{R}^{n\times n}$ are equivalent:

$$
\begin{aligned}
&A \text{ is invertible} \iff \det A \neq 0 \iff \operatorname{rank}(A) = n\\
&\iff \text{the columns of } A \text{ are linearly independent}\\
&\iff T_A \text{ is bijective} \iff A\vec{x} = \vec{0} \text{ only admits } \vec{x} = \vec{0}
\end{aligned}
$$

When $\det A = 0$, the image of $T_A$ has dimension less than $n$. The transformation ceases to be
injective: there exist $\vec{u} \neq \vec{v}$ with $T_A(\vec{u}) = T_A(\vec{v})$, and no map can
recover the argument from the image. The set of vectors that $A$ sends to the origin is the
**kernel** of $T_A$, and it has positive dimension exactly when $A$ is singular.

```python
B = np.array([[2, 4],
              [1, 2]])       # second column = 2 · first column

np.linalg.inv(B)
# LinAlgError: Singular matrix
```

NumPy raises an exception rather than returning an approximate result, which is the preferable
behaviour: a singular matrix has no inverse and any returned value would be spurious.

## Solving systems

The system $A\vec{x} = \vec{b}$ asks which vector has $\vec{b}$ as its image under $T_A$. With $A$
invertible the answer is $\vec{x} = A^{-1}\vec{b}$, unique by bijectivity.

```python
b = np.array([5, 3])
np.linalg.solve(A, b)     # array([2., 1.])
```

The equivalence is mathematical but not numerical: as argued in the lesson on linear systems, `solve` is preferable to
`inv` on grounds of cost and stability.
